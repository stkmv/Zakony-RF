# Стратегия: Сервис проверки сайтов на нарушение законов РФ

> Рабочее название: **LawScan**
> Версия плана: 3.0 (обновлён после реализации)
> Дата: 2026-04-22
> Источник законодательства: `/Zakony-RF.md` — актуально на апрель 2026 г.
> Последнее обновление статусов: 2026-04-22

---

## СУТЬ ПРОДУКТА

Пользователь вставляет URL своего сайта → нажимает кнопку → через 30–60 секунд получает:

- Список конкретных нарушений на человеческом языке
- Ссылку на закон и статью КоАП по каждому нарушению
- Сумму штрафа за каждое нарушение в рублях
- **Итоговую сумму «под угрозой»** — крупным шрифтом
- Краткую инструкцию: что именно нужно исправить

**Главное отличие от всех конкурентов:** никто не делает мультизаконный аудит с расчётом реальных штрафов. Мы — первые.

## СТЕК ТЕХНОЛОГИЙ

| Слой | Технология | Зачем |
|------|-----------|-------|
| Backend | Node.js + Express | HTTP-сервер, маршруты API |
| Краулер | Puppeteer (headless Chrome) | Загрузка страниц с JS, перехват сетевых запросов |
| HTML-парсинг | Cheerio | Анализ структуры DOM, поиск элементов |
| Frontend | Vanilla HTML + CSS + JS | Без фреймворков — быстро и просто |
| База знаний | JSON/JS конфиг | Штрафы, описания нарушений, законы |
| Хранилище | Нет в MVP | Результаты отдаются сразу в ответе |

> **Статус: `✅ ВЫПОЛНЕНА`**
> **Тип: Последовательная (выполняется первой)**
> **Блокирует:** Все остальные фазы

**Что делает этот агент:**
Создаёт файловую структуру проекта, устанавливает зависимости, поднимает базовый сервер. Это фундамент — без него ничто другое не запустится.

**Задачи:**
- [ ] Создать папку `site-checker/`
- [ ] Создать `package.json` с зависимостями: `express`, `puppeteer`, `cheerio`, `cors`
- [ ] Установить зависимости командой `pnpm install`
- [ ] Создать `server.js` — базовый Express-сервер на порту 3000
- [ ] Добавить маршрут `POST /api/check` — принимает `{ url }`, возвращает заглушку `{ status: "ok" }`
- [ ] Создать пустые файлы всех чекеров в папке `checkers/`
- [ ] Создать `fines.js` — конфиг штрафов (заполняется ниже)
- [ ] Создать `public/index.html` — пустая страница с формой
- [ ] Проверить: `node server.js` запускается без ошибок

**Ожидаемый результат:** Сервер поднят, все файлы созданы, зависимости установлены.

## ФАЗА 1А — ЧЕКЕР: ПЕРСОНАЛЬНЫЕ ДАННЫЕ (152-ФЗ)

> **Статус: `✅ ВЫПОЛНЕНА`**
> **Тип: Параллельная (запускается после Фазы 0)**
> **Параллельна с:** Фаза 1Б, 1В, 1Г, 1Д

**Закон:** ФЗ-152 «О персональных данных», КоАП ст. 13.11 (актуально с 30.05.2025)
**Файл:** `checkers/personal-data.js`

**Что проверяем и какие штрафы:**

| Проверка | Что ищем в коде | Штраф (юрлицо) |
|----------|----------------|----------------|
| Отсутствие политики конфиденциальности | Нет ссылки в footer с текстом «политика», «privacy», «конфиденциальност» | 150 000–300 000 ₽ |
| Политика конфиденциальности — шаблон | Текст политики содержит «[наименование организации]» или «[ФИО]» незаполненными | 300 000–700 000 ₽ |
| Форма без чекбокса согласия | `<form>` с `<input type="email/tel/text">` без рядом стоящего `<input type="checkbox">` | 300 000–700 000 ₽ |
| Чекбокс согласия проставлен по умолчанию | `<input type="checkbox" checked>` рядом с полем ПД | 300 000–700 000 ₽ |
| Согласие не оформлено отдельно (с 01.09.2025) | Чекбокс ссылается на общий документ (оферту, правила), а не на отдельное соглашение | 300 000–700 000 ₽ |
| Нет уведомления о сборе поведенческих данных | Используется аналитика кликов/просмотров без отдельного согласия | 300 000–700 000 ₽ |

**Технически:**
- Puppeteer загружает страницу
- Cheerio ищет footer ссылки по ключевым словам
- Cheerio перебирает все `<form>` и проверяет наличие чекбокса без атрибута `checked`
- Возвращает массив объектов `{ id, severity, law, article, title, description, fine_min, fine_max, how_to_fix }`

## ФАЗА 4 — СЕРВЕР: ИНТЕГРАЦИЯ И РАСЧЁТ ШТРАФОВ

> **Статус: `✅ ВЫПОЛНЕНА`**
> **Тип: Последовательная (запускается ПОСЛЕ фаз 1А–1Д и 2А–2В)**
> **Зависит от:** Фаза 0 + все фазы чекеров

**Файл:** `server.js`

**Что делает:**
1. Принимает POST `/api/check` с `{ url }`
2. Запускает Puppeteer — загружает страницу
3. Параллельно запускает все чекеры: `Promise.all([...])`
4. Собирает все нарушения в единый массив
5. Считает итоговые суммы: `fine_total_min`, `fine_total_max`
6. Дедупликация: одно и то же нарушение не дублируется
7. Сортирует по убыванию штрафа (самые серьёзные — первыми)
8. Возвращает JSON-ответ

**Формат ответа API:**

  "violations": [

**Обработка ошибок:**

## ФАЗА 7 — СУПЕРФИЧИ (POST-MVP)

> **Статус: `⬜ НЕ НАЧАТА`**
> **Тип: Параллельная (можно делать независимо друг от друга)**
> **Запускается после:** Успешного завершения Фазы 6

Каждая суперфича — отдельная задача для отдельного агента:

### 7А — PDF-отчёт
- Генерация PDF с логотипом, датой, списком нарушений и итоговой суммой
- Кнопка «Скачать отчёт» на странице результатов
- Библиотека: `puppeteer` (print to PDF) или `pdfkit`

### 7Б — Проверка нескольких страниц
- Краулинг в глубину: главная + страница контактов + страница с формой + политика конфиденциальности
- Максимум 5 страниц в MVP суперфичи
- Более точное обнаружение нарушений (особенно для чекера реквизитов)

### 7В — 168-ФЗ: Иностранные слова
- Подключение к нормативному словарю (gosslovar.ru API или собственная база)
- Поиск иностранных слов в тексте страницы
- Штраф: до 500 000 ₽ (в рекламе)
- Актуально с 01.03.2026

### 7Г — История проверок
- Сохранение результатов в базу данных (SQLite или PostgreSQL)
- Страница «Мои проверки» с историей
- Сравнение: «была ошибка — теперь исправлено»

### 7Д — Мониторинг по расписанию
- Повторная проверка сайта раз в месяц
- Email-уведомление при появлении новых нарушений
- Подписка: монетизация

### 7Е — Специализированные проверки
- Медицинские сайты: дисклеймеры в рекламе, прайс-лист (Приказ Минздрава)
- Образовательные сайты: 11 подразделов «Сведения об организации» (Приказ Рособрнадзора №1493)
- Финансовые сайты: дисклеймеры ЦБ РФ, ИНН/ОГРН в рекламе
